# Mandatory before public release

1. Obtain the complete unmodified GNU Affero General Public License version 3 text from https://www.gnu.org/licenses/agpl-3.0.txt and save as `LICENSE`. The file was not bundled automatically: this build environment cannot fetch the authoritative text.
2. Confirm copyright ownership and contributors' permission to license all original editor code under AGPL-3.0-or-later (or choose AGPL-3.0-only).
3. Check actual upstream licenses and bundled third-party notices from the exact Pyodide and PyMuPDF distributions; collect all required attributions.
4. Pin all dependencies and preserve corresponding source/build and installation information required by applicable licenses.
5. Link to this public repository from the deployed editor UI as `Source code & licenses`.
6. Publish the complete corresponding source at the same time as, or before, making the service public.
7. Review whether the isolated editor plus deployment integration changes the AGPL scope; seek qualified open-source legal advice if the separation matters.
